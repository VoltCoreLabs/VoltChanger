# Local assistant data

`item_ids.json` and `ability_ids.json` originate from the OpenDota Project's
[dotaconstants](https://github.com/odota/dotaconstants/tree/master/build) metadata.
Their MIT license is included as `ODOTA-LICENSE.txt`.

`voice_lines.json` is metadata extracted from this computer's installed Dota 2
`scripts/chat_wheel_heroes.txt` using `scripts/generate-assistant-voices.py`.
It contains local sound-event names and localization tokens, not audio files.
Sound playback is local preview only; no chat-wheel request is sent to other players.

Live item popularity and public match upgrade sequences are fetched from
`https://api.opendota.com/api/` with only a public hero ID/public match ID.
The public Valve timed averages endpoint is
`https://www.dota2.com/webapi/IDOTA2Plus/GetPlusHeroTimedStats/v001?hero_id=...`.
No player account, Steam token or private match data is sent by this worker.

These are frequency lists, public all-rank averages and one-match examples.
They are not Valve's contextual machine-learning recommendations.

`cosmetic_catalog.txt` is an equipable-definition allowlist generated by
`scripts/generate-cosmetic-catalog.py` from this computer's installed
`scripts/items/items_game.txt` schema (13,445 IDs in this snapshot).
It contains definition IDs and hero/global classification, not game models,
textures or audio. Automatic granting has been disabled at the user's request.
The manifest is retained only to identify untouched former auto-granted entries
for the reversible manual-inventory migration. Containers, tools and consumables
are excluded.

`hero_names.txt` records 128 hero IDs and localization tokens from the installed
`scripts/npc/heroes/npc_dota_hero_*.txt` files. The native hero-page level control
matches its displayed title against these tokens through Dota's own localizer;
it does not require a statistics API request to identify the browsed hero.

`dotacoach_heroes.txt` maps installed hero IDs to authoritative DotaCoach URL
slugs from the public `https://dotacoach.gg/en/heroes` catalog (2026-11-18).
It covers all 127 actual heroes in the installed schema; the target dummy is
excluded. It contains identifiers, not game assets or guide prose.

The opt-in Recommended Builds worker fetches public role guides from
`https://dotacoach.gg/en/heroes/{slug}/builds/{carry|mid|offlane|support}`.
These are DotaCoach authored recommendations with four item stages, an actual
skill order and chosen talents. Support is shared between positions 4 and 5.
The source provides no item purchase probabilities; no percentages are invented.
Only the hero and role are sent. Successful responses are cached separately in
`LOCALAPPDATA/OVR/cache/dotacoach`; errors retain an explicitly marked cache.
Dota2ProTracker is not requested by this worker after its HTTP 403 response.
