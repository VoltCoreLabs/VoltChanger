# Golos Text

`GolosText-Variable.ttf` is the unmodified Golos Text variable font (weights 400–900),
including Latin and Cyrillic, embedded into the application at build time.
The application registers it with GPUI before opening its first window.

Source: [Google Fonts / Golos Text](https://github.com/google/fonts/tree/main/ofl/golostext),
retrieved 2026-11-19. Upstream: https://github.com/googlefonts/golos-text.
