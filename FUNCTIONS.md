# Статус запрошенных функций

Проверено по коду и локальным проверкам 19 ноября 2026 года. «Реализовано» означает
наличие обработки и данных, а не подтверждение каждого сценария в живом матче.

| Запрос | Текущий результат |
|---|---|
| Rust / GPUI Kit, запуск игры и DLL | Реализовано. VoltChanger 0.2.0: glass-интерфейс, светлая/тёмная темы, иконка EXE и анимации. Тумблеры, DLL и журнал доступны из настроек. Защита от повторной загрузки, статусы инициализации и отмена ожидания сохранены. |
| Скины и личности | Реализована локальная экипировка и подмена моделей/ресурсов. Это не выдача предметов аккаунту. |
| Сохранение инвентаря | Единый inventory.cfg в LOCALAPPDATA/OVR/cache. После GC Welcome/подписки предметы восстанавливаются отдельными обновлениями после завершения пересборки кэша; предыдущие локальные порции отменяются. Входящие полные кэши не дополняются fake-объектами. Новый порядок требует проверки в игре. |
| Автоматический каталог | Отключён по просьбе пользователя из-за лагов. Однократная миграция архивирует нетронутые неэкипированные записи каталога. Старый ручной инвентарь, экипировка, изменённые стили и атрибуты сохраняются. Полные убранные записи остаются в архиве общего кэша. Новые вещи добавляются вручную. |
| Окно получения предметов | Пользователь подтвердил отсутствие массового окна. Локальные вещи выдаются уже просмотренными. |
| Курьеры | Подмена наземной/летающей модели выбранного курьера только при точном совпадении владельца со своим player ID. Пользователь подтвердил применение. |
| Эмблема только своего героя | Локальная эмблема исключается по fake item ID из нативного списка предметов чужого героя до создания эффектов. Пользователь подтвердил исправление. |
| Оригинальная сетка Dota с WR/PR | Реализовано, пользователь подтвердил работу поиска и сетки. Добавляются подписи к исходным карточкам, без копий и замены категорий. |
| Meta Tracker, Hero Win Rate, Hero Pick Rate | Публичные данные OpenDota, оценочный PR, обновление с кэшем. Ранг/линия меняют цифры. Совместного среза ранга и линии нет. |
| Сортировка меты | Отдельная сортировка WR/PR из прошлой собственной сетки удалена по просьбе сохранить оригинал. Расположение теперь управляется штатной сеткой Dota. |
| AI Pick / AI Build Assistant | ИИ отменён по просьбе пользователя. Есть публичные показатели героев и частотные сборки без ИИ. |
| Lane Recommendations | Статистика сценариев линий OpenDota. Не определяет оптимальный пик под полный драфт. |
| Aspect Statistics | Только небольшой публичный набор матчей с hero_variant. При проверке источник не отдавал пригодных вариантов; полноценной статистики аспектов сейчас нет. |
| Shop Builds, Item Popularity | Сборки OpenDota по четырём стадиям только внутри выбранного штатного Plus Guide. Сборки игроков и ItemBuild не заменяются; пользователь подтвердил их открытие. Контекстный алгоритм Valve не реализован. |
| Рекомендованные сборки | Отдельный переключатель в лаунчере и игровых настройках. При включении заменяет содержимое выбранного гайда в штатной колонке магазина сборкой DotaCoach: позиция, четыре этапа предметов, способности и рекомендуемые таланты. При выключении возвращает исходный гайд. Позиции 4/5 используют общий support-гайд источника. Проценты покупок не выдумываются. Разбор проверен на реальных данных; пользователь подтвердил отображение и возврат обычного гайда в игре. |
| Player Analyzer / Player Statistics / Player History | До 100 доступных публичных матчей, WR, KDA, частые герои, страницы истории. Для своей истории есть путь запроса к GC и публичный резерв; фактический ответ GC ещё не подтверждён. |
| Участники текущего матча | Во время выбора героев автоматически открывается сворачиваемая панель с последними 15 публичными матчами, W/L, до трёх частых героев, WR/PR по выборке и линией. В матче остаётся доступ через Tab. Идентификаторы берутся только из предоставленных клиентом строковых SteamID. Новую панель пика нужно проверить. |
| Итоги матча | Панели помощника скрываются в PostGame. Добавлена диагностика штатной страницы и кнопка перехода к таблице при уже загруженных данных. По отдельной кнопке доступна реальная локальная K/D/A. Получение штатного отчёта GC не гарантируется и пока не подтверждено. |
| Pick Analyzer | Частые герои из публичных агрегатов и последних 30 доступных матчей. |
| Ban Suggestions | Эвристический приоритет по частоте и победам на оригинальных карточках. Ручной account ID или публичные ID соперников, если клиент их предоставляет. Без автоматического бана. |
| Private Profile Analysis | Обход закрытого профиля не реализован. Только публичные агрегаты и ранее полученный публичный кэш текущего процесса. |
| Smurf Detection | Объяснимые показатели WR/KDA с минимальной выборкой. Не доказательство смурфа и не обученная модель. |
| Win/Loss Streaks | Серии по доступной истории; пропуски могут искажать непрерывность. |
| Role Detection | Предположение о привычной линии. Не различает позиции 4 и 5. |
| Ward Tracker | Последние подтверждённые наблюдения видимых вардов. Нет поиска скрытых объектов. Живые переходы видимости требуют проверки. |
| Show Courier | След из последних видимых точек, не текущий путь в тумане. Проекция на мини-карту требует проверки совпадения координат. |
| Jungle Helper | До пяти ближайших видимых лагерей, без оценки силы, безопасности или оптимального фарма. |
| Перетаскиваемая панель | Реализованы перенос, сворачивание и сохранение положения. |
| Индикаторы фарма / типы полученного урона | В коде есть публичные ориентиры и адаптер данных своего игрока. В последнем журнале структура данных игрока не поддержана; получение значений в этой сессии не подтверждено. |
| Штатные рекомендации Dota+ | Не реализованы. Локальный статус подписки не предоставляет серверные ответы Valve. |
| Штатный тир героя | Общий сохранённый выбор применяется к матчу, странице героя, номеру/иконке в штатной сетке меню и пика, подсказке карточки и значкам с подтверждённым собственным account ID. Чужие профили не подменяются. XP и награды не заменяются. Возврат настоящего уровня снимает подмену. Новое распространение на остальные экраны требует проверки. |
| Голосовые фразы | Локальный звук и текст подтверждены, затем пользователь сообщил о краше. У локально открытых реплик отключён лишний исходный запрос на сервер: остаются Game.EmitSound и DOTAChatMessagePrintf. Для обычных реплик сохранено штатное действие. Дампы также выявили падение слушателя SO cache; изменено время восстановления инвентаря. Отсутствие повторного краша нужно проверить. |
| Ландшафты | Поддержаны class1000, ранний initialized econ view и повтор native resolver с текущим выбором внутри прошедшего проверки AssetSystem callback. Пользователь подтвердил морской ландшафт в новом матче с ботами. Для смены нужно перезайти на карту. |
| Предпросмотр ландшафта при наведении | Пока не реализован. Найдены реальные preview-карты и штатный компонент сцены, но связывание с наведённой карточкой ещё не установлено. |
